# Roadmap

- **Phase 0 — Setup:** repo scaffolding, CI, Docker.
- **Phase 1 — Core pipeline:** CV parser, AI provider layer, query generation, web search, page fetching, JSON-LD extraction, connectors, normalizer, filters, dedup.
- **Phase 2 — Matching:** embeddings, hard filters, scoring, tiers, evaluation set.
- **Phase 3 — Interface:** upload page, preferences form, result cards, loading/error/empty states, editable filters.
- **Phase 4 — Launch:** README demo, more connectors, good-first-issues.

Post-MVP backlog: saved profile (SQLite), application tracker, tailored CV/cover letter, skill gap view, scam warning, daily digest, browser extension, community company list.
